Projects

Bolt

Custom Programming Language

Bolt is my custom programming language that I built so I could understand programming concepts faster. I used Python as the Hosting language. It uses a hybrid interpretation and bytecode compilation system. It can run line by line and as a compiled file. It is powerful enough to let users make basic system and algorithm. The main power of Bolt is its Module system. You can use Python to make advanced modules and use Bolt to make programs using those modules while making the syntax easy and clean.
